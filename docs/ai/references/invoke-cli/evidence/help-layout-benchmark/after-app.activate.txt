Bring a target macOS app to the foreground before a foreground-dependent step.

Usage: auv invoke app.activate [OPTIONS]

Options:
      --target <TARGET>    Required app:<bundle-id> (bare ids accepted); window and display targets are unsupported.
      --dry-run            Validate the operation without performing it.
      --no-overlay         Disable live visual overlay presentation.
      --store-root <PATH>  Directory used to persist the recorded run and artifacts.
      --json               Render machine-readable JSON output.
      --compact-json       Render single-line JSON with all result, verification, failure, and artifact fields preserved.
      --detail             Include diagnostic detail in human output.
      --wide               Include extra columns in human table output.
  -h, --help               Print help

Examples:
  auv invoke app.activate --target com.apple.TextEdit
