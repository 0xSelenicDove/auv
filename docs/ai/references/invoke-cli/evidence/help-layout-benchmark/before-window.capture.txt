Capture one single-display window without activating it and emit a coordinate contract (macOS and Linux). Linux uses an AT-SPI display crop.

Usage: auv invoke window.capture [OPTIONS]

Options:
      --title <TEXT>
          Window title text used to select the capture target

      --target <TARGET>
          Optional app:<bundle-id> (bare ids accepted); window and display targets are unsupported.

      --dry-run
          Validate the operation without performing it.

      --no-overlay
          Disable live visual overlay presentation.

      --store-root <PATH>
          Directory used to persist the recorded run and artifacts.

      --json
          Render machine-readable JSON output.

      --compact-json
          Render single-line JSON with all result, verification, failure, and artifact fields preserved.

      --detail
          Include diagnostic detail in human output.

      --wide
          Include extra columns in human table output.

  -h, --help
          Print help (see a summary with '-h')

Examples:
  auv invoke window.capture --title Untitled
  auv invoke window.capture --target com.apple.TextEdit --title Untitled

On Linux, app targets match the AT-SPI AccessibleId in window.list (BUNDLE in --wide output). Use --title when that field is absent. Linux captures a display crop and does not activate or unocclude the window.
