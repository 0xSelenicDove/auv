## 4. 关键技术发现与底层根因

### 1. Windows 桌面隔离 (Desktop Isolation) 穿透
- **现象**：后台任务执行时，`SendInput` 报错 `ERROR_ACCESS_DENIED (5)`，`PostMessageW` 投递无位移。
- **根因**：自动化运行环境位于独立桌面上（`exebox-...`），而 Minecraft 运行在 `Default` 输入桌面。Windows UIPI 机制隔离了跨桌面的消息与输入队列。
- **解决**：在 Win32 输入抽象层通过 `OpenInputDesktop(0, 0, 0x01FF)` 动态获取输入桌面句柄，并在发送消息与按键前调用 `SetThreadDesktop(hdesk)`，成功穿透桌面隔离，使 2Hz 移动完全稳定生效。

### 2. 状态保护：条件式 ESC 响应
- **现象**：T-M3 开始前盲目调用 `press_esc()` 会触发游戏主菜单（Pause Menu），导致游戏暂停、按键被 GLFW 完全吞噬。
- **解决**：读取遥测 `screen_state`。仅在 `screen_state != "in_game"` 时按 ESC 关闭残留 UI，若为 `in_game` 则严禁按 ESC。

### 3. 体素网格中心与到达阈值校准
- **现象**：若到达阈值设为 `< 3.5m`，导航器在距体素中心 `(-51.5, 265.5)` 达 3.32m 时停步，此时距方块西北角真值 `(-52.0, 265.0)` 仍有 3.78m（微超 3.5m 门禁）。
- **解决**：将体素中心到达阈值设为 `< 2.5m`（停止于 1.84m），此时距真值距离为 2.27m，稳妥落在 `< 3.5m` 验收标准内。
