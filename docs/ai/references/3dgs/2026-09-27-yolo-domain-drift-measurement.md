## 1. 实验目的与条件

本测试对未微调的 YOLO-World v2（`yolov8s-worldv2.onnx`）在 Minecraft 实机截图（M2 Session `v01`, `v02`, `v03`）上的零样本开放词汇检出能力进行定量测量，评估在生产作战守则（置信度 $\ge 0.50$ + 静态白名单）下，视觉感知模块对游戏体素方块的真实识别与幻觉抑制情况。

### 固化 Prompt 实验条件（测试前定死，测试中不改）
- **白名单类别（生产级 Prompts）**：`["grass block", "chest", "furnace", "crafting table", "door", "torch"]`
- **已知幻觉探针（负样本类别）**：`["bed"]`（验证 Step 4 审计发现的误报是否复现）
- **真值依据**：
  - `v01`/`v02`：准星指向草方块 `(-22, 81, 43)`，屏幕中心 $(427.0, 240.0)$ 附近。
  - `v03`：视线指天（`raycast_hit = None`），画面无实心目标，期望无有效检出。

## 3. 四大核心问题回答（基于硬指标）

### 问题 1：草方块被检出了吗？什么标签？置信度多少？bbox 是否覆盖屏幕中心？
- **回答**：**没有被有效检出**。
  - 在 `v01` 帧中，`"grass block"` 的全图最高置信度仅为 **0.0052**（0.52%）。
  - 在 `v02` 帧中，走近后 `"grass block"` 最高置信度仅升至 **0.0183**（1.83%）。
  - 两帧中没有任何候选框的置信度能达到 0.05 的最低展示线，更未覆盖屏幕中心。

### 问题 2：`0.50 + 白名单` 门控后，每帧还剩几个检出？
- **回答**：**每帧幸存者数量全部为 0**。
  - `v01`: 0
  - `v02`: 0
  - `v03`: 0

### 问题 3：已知的 `"bed"` 幻觉复现了吗？在什么置信度？被门控拦下了吗？
- **回答**：**完全复现，且呈现强烈的距离相关性**。
  - `v01`: `"bed"` 探针在左下泥土草阶处的置信度为 **0.1142**。
  - `v02`: 走近后，同一体素台阶被判定为 `"bed"` 的置信度暴增至 **0.4490**（轻松穿透了常规的 0.25 阈值，直逼 0.50 警戒线）。
  - **是否被拦下**：是的，被双重防御成功拦截：
    1. 语义白名单层（`"bed"` 不在白名单内）；
    2. 置信度阈值层（0.4490 < 0.50）。

### 问题 4：关键失败模式验证
- **回答**：**关键失败模式完全成立，构成了不可逾越的致命断裂**。
  - 实验证明：通用预训练的 CLIP/YOLO-World 权重未学习 Minecraft 的低多边形网格与像素纹理分布。它将草方块台阶特征强关联到了床上用品类（置信度 0.4490），而对真正的体素名称 `"grass block"` 只有 0.0183。
  - **后果**：如果依赖目前的白名单机制，虽然阻断了将草地错认为床的虚警（False Positive = 0），但同时也**百分之百误杀了真实物体的检出（False Negative = 100%）**。单纯调节全局阈值无法解决此类“置信度颠倒”的域漂移问题。

---

## 4. 最终裁决

### 裁决结论：**【必须微调】**

**结论依据**：
1. **门控不够用**：现有的 `0.50 + 静态白名单` 属于**纯消极防御**（只能防虚警，无法促成真阳性）。在游戏真实截图下，真实目标由于域漂移，置信度只有 0.01 级别，导致在视觉感知链路下 Recall 完全为 0。
2. **证据确凿完整**：在冻结的 Prompt 严密实验条件下，连续 3 帧图像无一例外呈现体素语义盲区。若要在黑盒或纯视觉感知场景下建立鲁棒地标，必须针对 Minecraft 领域数据集对 YOLO-World 的视觉特征提取器或文本对齐头进行微调（In-domain Fine-tuning），否则视觉反投影链路将永远处于门控阻断状态。
