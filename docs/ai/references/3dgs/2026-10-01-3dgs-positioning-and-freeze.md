# 3DGS 系统生态位推演与全向冻结决议（2026-10-01）

> **口径声明**：
> - **事实** = 已合入提交 + 实机硬核消融数据；
> - **推演** = 基于 3DGS 物理与视觉特性的系统级生态位分析；
> - **决策** = 用户 2026-10-01 明确裁定：**“这三个位置现在一个都不动”**。
> - **文档职责**：记录思考推演与冻结边界，防止未来重复探索已证伪路径或无批准展开边缘功能。

---

## §1 背景与动因

在 3DGS 空间记忆探索线中，我们先后通过两轮严格实证关闭了“3DGS 进 Agent 核心循环”的设想：
1. **2026-09-25（Slice B Closeout，Commit `880a8c48` 链条）**：
   实证稀疏视角（2~3 视角）下 3DGS 严重过拟合训练视角（seen 18.85dB / SSIM 0.514），对未见视角完全无法泛化（holdout 7.54dB / SSIM 0.244）。
2. **2026-09-30（traj-geo-spike，Commit `bcdcf867`）**：
   实证人类常规游玩式轨迹（前向为主、微小摆头、单目多 pass 徘徊）下，由于缺乏大基线横向视差，光流退化为中心膨胀，3DGS 物理几何严重发散（到 GT 表面中位数距离 2.041m，表面完整度仅 4.1%）。95.9% 的物理结构缺失，形成大量半空浮动高斯点。

在确认 **“3DGS 不能作为 Agent 在线空间记忆（3DGS-as-memory）”** 之后，自然引申出一个更深层次的架构问题：
**如果 3DGS 不在 Agent 的动作记忆循环里，那它在 AUV / AIRI 的全景体系中到底应该放在哪？**

---

## §2 已排雷区域：它绝对不适合放的位置

**严禁放入 Agent 的实时感知-规划-动作闭环（Real-time Action / Memory Loop）。**

- **输入输出错配**：
  Agent 进行空间推理与动作决策（避障、寻路、开箱、交互）需要的是**离散语义符号**（“这是箱子”）、**确定性度量几何**（“在前方 3.2m，bounding box 为 1m×1m×1m”）、**碰撞阻挡状态**（“可行走/不可行走”）。
  3DGS 输出的是**连续辐射场与 RGB 视锥渲染**，它没有实体边界，不包含语义标签，更无法提供坚硬的碰撞网格。
- **算力与延迟悬殊**：
  结构化空间记忆（`SpatialMemoryStore` 配合 S2 Uniform Grid 空间哈希）去重与半径查询在 100k 规模下仅需 **1.6µs**；而 3DGS 每次训练需数秒至数十秒，体素/高斯射线遍历需数毫秒且依赖显卡。
- **几何漂移不可容忍**：
  游玩轨迹下 2.04m 的几何中位数误差，会导致 Agent 产生严重的“虚空判阻”或“穿模碰撞”。

## §3 三个潜在生态位推演（Three Candidate Positions）

3DGS 的本质优势是**基于稠密多视角图像的高保真辐射场渲染（Novel View Synthesis）**。脱离实时决策循环后，它存在三个理论上自洽的系统生态位：

```
                    ┌──────────────────────────────────────────────┐
                    │            AUV / AIRI 系统全景               │
                    └──────────────────────────────────────────────┘
                                          │
        ┌─────────────────────────────────┼────────────────────────────────┐
        ▼                                 ▼                                ▼
【生态位 1：人机交互与审计】         【生态位 2：仿真与脑海建模】          【生态位 3：独立生产工具】
人机数字孪生 (Digital Twin)        环境模拟器 (World Gym)             资产导出工具 (Scan Tool)
  - 人类复盘审计                     - Agent 在脑海中虚拟漫游           - 环绕拍摄生成 3D 资产
  - 自由视角 3D 漫游回放             - 离线合成训练数据                 - 导出 .splat / WebViewer
  - 空间 Grounding Prompt            - 验证新视点可见性                 - 交付给人类设计师
```

### 生态位 1：人机交互与复盘层 —— 离线 3D 数字孪生（Digital Twin & Replay Artifact）

* **定位**：AUV 核心使命中 “Run Recording / Artifact Capture / Inspection” 的视觉升级形态，**面向人类（操作员、开发者、审计员）**。
* **业务场景**：
  Agent 在复杂 3D 场景（或无人机、机器人录制的物理环境）中执行完长程任务后，若伴随有多角度环视数据，后台自动编译出一个轻量级 `.splat` 文件作为运行产物（Artifact）。
* **核心价值**：
  1. **自由视角复盘（Free-Fly Inspection）**：人类无需打开游戏或远程桌面，直接在 Web 浏览器（基于 WebGL/WebGPU 3DGS 查看器）中以第一/第三人称自由飞行漫游，审查 Agent 执行任务时的环境全貌；
  2. **3D 空间提示（Spatial Grounding Prompt）**：人类可在 3D 孪生场景中鼠标点选方块或区域，直接生成世界坐标锚点下发给 Agent：“去清理这个角落”。
* **架构关系**：3DGS 不是 Agent 的决策输入，而是**Agent 执行过程沉淀的审计资产（Artifact）**。

### 生态位 2：环境模拟器与“假想沙盒”（Simulation Gym & World Model）

* **定位**：Agent 外部的“虚拟显卡与物理沙盒”，为智能体提供脱离实机的高保真视觉推演。
* **业务场景**：
  高风险、高成本或受限环境（如物理真实世界、无沙盒的封闭系统）。通过预先稠密扫描建立 3DGS 孪生体。
* **核心价值**：
  1. **合成感知训练数据（Synthetic Data Engine）**：在 3DGS 场景内架设虚拟摄像机，自动生成任意角度、光照的多样化合成图像，专门用于训练和增强下游的轻量级感知模型（YOLO、单目深度等），免除实机采图标注成本；
  2. **视点假想（Visual Rollout / "Imagination"）**：“如果我向左前方跨越 5 米，从那个障碍物后面会看到什么？”调用 3DGS 渲染出前瞻视角画面喂给 VLM 验证假设，无需在真实世界中贸然肉身探路。
* **架构关系**：3DGS 充当 **Environment / Simulator**，Agent 站在它的外部与其交互。

### 生态位 3：独立外挂资产扫描工具（Specialized Scan Tool / Offline MCP Skill）

* **定位**：独立于 Agent 核心执行体的专用 MCP 工具（如 `auv-tool-3dgs-scanner`）。
* **业务场景**：
  Agent 不将 3DGS 用于自身导航，而是作为一种**生产技能（Skill）**交付给终端用户。
* **核心价值**：
  用户向 Agent 下达工作指令：“对这个房间/这座建筑物进行 3D 建模并导出模型”。Agent 自主规划围绕目标的**环绕轨道航线（Turntable / Orbit Trajectory）**，采集密集多视角帧，调用后台 Brush 训练并输出标准 3D 高斯点云或 Mesh 交付给人类设计者。
* **架构关系**：Agent 是**调度者**，3DGS 是**产物生成器（Asset Builder）**。

## §4 全向冻结决议（The Complete Freeze Policy）

根据用户 2026-10-01 明确裁定：**“这三个位置现在一个都不动”**。

### 4.1 冻结状态定义

| 候选位置 | 当前状态 | 冻结细则与红线 |
|---|---|---|
| **生态位 1：数字孪生回放** | **DEFERRED (搁置)** | 不搭建 WebGL 查看器，不编写 Run Record 到 `.splat` 的自动生成流水线。 |
| **生态位 2：仿真沙盒推演** | **DEFERRED (搁置)** | 不启动基于 3DGS 的合成数据生成，不编写 VLM Visual Rollout 接口。 |
| **生态位 3：外挂扫描工具** | **DEFERRED (搁置)** | 不封装 3DGS MCP 工具，不开发针对特定物体的环绕扫描规划算法。 |

### 4.2 解锁触发条件（Trigger to Unlock）

本决议为持久性决策，未来除非满足以下**全部显式条件**，否则严禁任何人以“先写个原型看看”为由重新启动相关开发：
1. **生态位 1 解锁条件**：AUV 核心 Viewer/Web 前端进入正式排期，且拥有稳定、确定性的多视角稠密轨迹采集协议；
2. **生态位 2 解锁条件**：出现真实环境无法在线采集的重型感知瓶颈，且有证据证明 3DGS 合成视图能显著提高下游闭集检测泛化性；
3. **生态位 3 解锁条件**：项目主线正式批准 3D 资产生成为第一方对外产品能力；
4. **统一前置门槛**：必须获得项目 Owner 的书面专项 Slice 批准。

## §5 当前核心主线锁定

AUV 的根本使命是 **Application Use Via**：
- 统一的 typed invoke API；
- 高确定性的驱动层动作投递（`auv-driver`）；
- 确定性、无幻觉的**结构化空间记忆（Structured Spatial Memory）**：
  - **感知**：闭集 YOLOv8（轻量、低延迟、抗域漂移）；
  - **几何**：显式射线投射 / 空间投影变换（毫米级确定性坐标）；
  - **存储**：Uniform Grid 空间哈希（微秒级 O(1) 检索、稳健遗忘修剪、跨进程持久化）；
  - **控制**：视觉伺服 + 罗盘姿态闭环（实测 100% 召回通过）。

所有研发资源与工程注意力继续完全聚焦于核心主线，不向任何边缘 3D 重建实验分散精力。
