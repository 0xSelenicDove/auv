## 1. 任务背景与核心目标

在 Step 6a 中，我们验证了基于 Minecraft Fabric 遥测数据与相机视锥体反投影的自动标注流水线（Autolabel Pipeline），测得 3,868 帧/秒的极高标注吞吐，但当时录制数据全为野外草方块（9,611 框均为 `grass_block`）。

本阶段（Step 6b）的目标：
1. **村庄/定向场景数据补全**：在真实 Minecraft 环境中录制包含其余 5 类关键方块（`chest`, `furnace`, `crafting_table`, `door`, `torch`）的对齐截图与遥测数据；

3. **闭集小模型训练**：在本地 RTX 4070 Ti 上完成 YOLOv8n（3.0M 参数）50 轮训练，输出逐类 AP 与全局 mAP 指标；
4. **ONNX 导出与工程化校验**：导出并校验 ONNX 权重，测量推理时延；
5. **历史域漂移帧闭环对齐**：使用在 Step 4/Step 6a 中使 YOLO-World 零样本完全失效并出现幻觉的 `v01`/`v02`/`v03` 实机截图，对新模型进行同条件盲测，对比 Recall、置信度与误报率。

## 6. 核心结论与工程裁决

1. **自动标注数据管线闭环成立**：
   从 Fabric 模组读取三维坐标与视锥体矩阵，通过 `autolabel.rs` 在单台机器上以 900+ fps 的速度实时生成高质量 2D YOLO 边界框。几何投影与遮挡剔除准确，有效避免了将地表遮挡下的物体虚假标注。
2. **闭集微调彻底粉碎域漂移与幻觉**：
   相比零样本 CLIP 类视觉大模型的虚弱表征，仅用 3M 参数的 YOLOv8n 小模型在 50 轮微调后即可实现 **0.926 mAP@0.5**。在具有挑战性的真值漂移帧上，草方块识别置信度从 **0.01 下滑逆转为 0.92 坚挺召回**，误报完全归零。
3. **推理性能满足实时高帧率要求**：
   ONNX 导出后在 CPU 上即可跑满 30 FPS（31.5ms），在 GPU 上仅需 1.8ms 前向计算，完全满足 Live Agent 循环（1Hz 甚至 10Hz）的实时性需求。
4. **后续演进建议（Step 6c）**：
   将 `best.onnx` 正式接入 Rust 端 `crates/auv-game-minecraft/src/visual_perception.rs`（替换原占位的 zero-shot ONNX 加载器），实现真正的生产级方块视觉感知闭环。
